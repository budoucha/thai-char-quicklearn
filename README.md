# タイ文字超速習

タイ文字を、まず「見て音にできる」状態まで短時間で持っていくためのブラウザ学習ドリルです。

声調や細かな正書法を最初から全部覚えるのではなく、**母音 → 子音 → 音節 → 複数音節**の順に段階的に読む練習をします。

## ステージ

- **1A 母音** — 母音記号を読む
- **1B 子音** — タイ文字44子音を読む
- **2 子音＋母音** — CV音節を読む
- **3 音節** — 子音＋母音＋末子音（CVC）を読む
- **4 2音節** — 音節境界の表示なしで2音節を読む
- **5 3音節以上** — 3〜4音節を自分で分解して読む

すべてのステージは最初から自由に選択できます。

各ステージで10問連続正解すると達成扱いになります。達成後は次のステージへ進むか、そのステージを継続するかを選べます。1A・1Bでは、もう一方の基礎ステージへ移ることもできます。

## 方針

- 声調は現段階では正解判定に含めません。
- ただし、声調クラスの違いを理由に文字を省略することはせず、子音は44字すべてを出題対象にしています。
- 同じ初頭音になる複数の子音字も、それぞれ個別に出題します。
- 末子音も代表字だけでなく、同じ末音になる複数の綴りを出題します。
- 複数音節問題ではタイ文字側に分かち書きを入れず、音節境界も自分で判断します。

## 実行

`index.html` をブラウザで開くだけで動作します。ビルドは不要です。

GitHub Pagesで公開する場合は、Repository Settings → Pages から `main` ブランチを公開元に指定してください。

## 表記について

回答に使うローマ字は学習用の簡略表記です。正式なRTGS転写そのものを目的としたものではありません。
